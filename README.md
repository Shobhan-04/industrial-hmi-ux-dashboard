# Industrial HMI Monitoring Dashboard

A conceptual UX/UI case study for an industrial machine monitoring and alarm-management HMI.

## Project Overview

This project explores the design of a Human-Machine Interface (HMI) for factory operators to monitor machine health, production status, system performance, and critical alarms from a centralized dashboard.

## Target User

Factory machine operator.

## Core Goals

- Monitor overall plant health
- Identify machines requiring attention
- View machine-level technical information
- Prioritize active alarms
- Inspect alarm details
- Acknowledge alarms through a clear workflow

## Disclaimer

This is a conceptual UX/UI case study. Machine data, alerts, thresholds, and operational recommendations are illustrative and are not intended for use in real industrial control systems.
