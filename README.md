# Industrial HMI Monitoring Dashboard

A conceptual **UX/UI case study for an Industrial Human-Machine Interface (HMI)** designed to help factory operators monitor machine health, production status, technical metrics, and critical alarms through a centralized dashboard.

The project focuses on **user flow, information hierarchy, wireframing, accessibility, visual design, and interactive prototyping** using Figma.

---

## 🎯 Project Objective

Industrial operators often need to monitor multiple machines while quickly identifying abnormal conditions and deciding which issues require attention.

This project explores how an HMI can organize complex technical information into a clear and structured interface that supports:

* Plant-level monitoring
* Machine-level inspection
* Alarm identification and prioritization
* Technical information review
* Clear operator actions

---

## 👤 Target User

**Primary User:** Factory Machine Operator

### Goals

* Monitor machine status
* Detect abnormal conditions
* Identify critical alarms
* Inspect technical metrics
* Respond to issues efficiently

### Pain Points

* Large amounts of technical information
* Difficulty prioritizing alarms
* Important information competing with secondary data
* Need for clear and predictable navigation

> **Note:** The persona and requirements are conceptual and were not derived from real operator interviews.

---

## 🔄 User Flow

The core operator workflow is structured around:

```text
Plant Overview
      ↓
Machine Details
      ↓
Alarm Center
      ↓
Alarm Details
      ↓
Acknowledge
```

The flow separates **plant-level awareness** from **detailed alarm investigation**, allowing information to be progressively explored when required.

---

## 🧩 Key Screens

### 1. Plant Overview

Provides a high-level view of:

* Overall machine status
* Production status
* Active alarms
* Machine availability

### 2. Machine Details

Allows operators to inspect:

* Machine performance
* Technical metrics
* Operational status
* Recent alerts

### 3. Alarm Center

Organizes active alarms by:

* Severity
* Machine
* Alert type
* Current status

### 4. Alarm Details

Provides:

* Alarm description
* Affected machine
* Current metric and threshold
* Recommended actions
* Alarm acknowledgement

## ♿ Accessibility Considerations

The interface incorporates accessibility-focused principles such as:

* Clear information hierarchy
* Consistent navigation
* Readable typography
* Explicit action labels
* Status communication using text and visual indicators rather than color alone
* Clear distinction between primary and secondary information
